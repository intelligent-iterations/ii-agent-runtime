# Security

Report vulnerabilities privately to **security@intelligentiterations.com** or
through [private vulnerability reporting](https://github.com/intelligent-iterations/ii-agent-runtime/security/advisories/new).
Include the affected revision and reproduction steps. Do not publish credentials.

Scope includes invocation authorization and admission checks, GitHub App token
scoping, worker provisioning and cleanup, worker network isolation, the worker
gateway, command execution, retained run artifacts and the Software Factory example.
Provider and harness vulnerabilities should also be reported to their respective
maintainers.

We aim to acknowledge reports within three business days.
